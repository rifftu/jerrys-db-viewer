# Rules

- This is a personal project and is NOT Blockit-related. The other repos in this directory (~/git/) are for building and working on Blockit products. The information in those directories should not leak into this one.
- I am the sole owner of this git repo. Any change you make can be committed and pushed directly to main, unless I ask you to create a PR
- Both Claude and Chatgpt will be used, so no agent-specific instructions
- Track lessons learned in LESSONS.md
- The user will continuously make feature requests. It is important that this app stays very fast and lightweight. If a feature request can only be satisfied by increasing latency or significantly increasing complexity, warn the user before proceeding.
